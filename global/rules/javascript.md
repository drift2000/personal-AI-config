# JavaScript, TypeScript, React, React Native

- Менеджер пакетів — за lock-файлом (`package-lock.json`/`yarn.lock`/`pnpm-lock.yaml`); не змішувати і не оновлювати lock без потреби.
- Не додавати залежності без погодження; перевіряти, чи потрібне вже є в проєкті.
- TypeScript: не послаблювати `tsconfig` і не розставляти `any`/`@ts-ignore` для обходу помилок.
- React: дотримуватися наявного підходу до стану, стилів і структури компонентів; ключі списків стабільні; ефекти з коректними залежностями та cleanup.
- React Native: враховувати обидві платформи; нативні модулі й зміни в `ios/`/`android/` — окремо погоджувати.
- Безпека фронтенду: без `dangerouslySetInnerHTML`/`innerHTML` з неекранованими даними; секрети не потрапляють у клієнтський бандл.
- Legacy JS (jQuery у CMS-шаблонах): не переписувати на фреймворк без запиту.
- Перевірка: скрипти проєкту (`lint`, `test`, `build`, `tsc --noEmit`).
