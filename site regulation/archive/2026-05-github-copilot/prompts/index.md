- Parser prompts: `.github/prompts/parser.prompts.md`
- Importer prompts: `.github/prompts/importer.prompts.md`
- Enrichment prompts: `.github/prompts/enrichment.prompts.md`
- Tests prompts: `.github/prompts/tests.prompts.md`
- CLI prompts: `.github/prompts/cli.prompts.md`
- PR & Review prompts: `.github/prompts/pr.prompts.md`
- Clarifying prompts: `.github/prompts/clarify.prompts.md`

Відкрий потрібний файл і використай шаблонні змінні (`{{file_path}}`, `{{source_name}}`, `{{inchikey}}`) при виклику.
