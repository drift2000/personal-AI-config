PR & Review Prompts
====================

1) PR description helper
--
Prompt: "Згенеруй текст для PR, що додає парсер `{{source_name}}`: короткий опис змін, де знаходиться код, як запускати тестовий імпорт (команди), і чекліст того, що перевірити при рев'ю (edge-cases, ідемпотентність, логування)."

2) Code review checklist
--
Prompt: "Дай чекліст для code-review парсера/імпортера: тест-кейси, ідемпотентність, транзакції, error handling, логування/метрики, конфігурація таймаутів для enrichment, документація README."
