# 0001 — Цільова модель: мульти-стор ocStore

Status: accepted
Date: 2026-10-26

## Context

Зараз кожна мова — окремий сайт Joomla 3 + JBZoo: повноцінні UA і RU (два окремі магазини) та урізані магазини іншими мовами з неповним асортиментом. Ціль — один ocStore 3.0.5.1 на PHP 8.3.

## Decision

- Мульти-стор OpenCart. Store 0 — повний магазин, UA + RU. Store 1..N — урізані магазини, кожен зі своєю мовою, доменом і асортиментом.
- Один товар = один `product_id` з описами всіма мовами; асортимент магазину задається через `*_to_store`.
- Міграція поетапна: фаза 1 — store 0, українська (джерело — UA-магазин); фаза 1b — RU-магазин (зіставлення за SKU); фаза 2 — урізані магазини.

## Consequences

- Мови в OC глобальні — потрібна доробка «дозволені мови магазину» (перемикач + редірект).
- Ціни спільні для всіх магазинів; чи потрібні окремі ціни — відкрите питання (з'ясуємо аудитом фази 2).
- `migration_map` містить `source` з першого дня; SKU — ключ зіставлення товарів між магазинами.
