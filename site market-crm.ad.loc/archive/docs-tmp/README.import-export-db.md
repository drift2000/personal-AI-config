Щоб перенести дані з SQLite у PostgreSQL для Django-проєкту, виконайте такі кроки:

### 1. Встановіть необхідний пакет
Встановіть [django-import-export](https://django-import-export.readthedocs.io/) або використайте стандартний інструмент Django:

```
pip install django-import-export
```

Або використайте стандартний dumpdata/loaddata:

### 2. Зробіть дамп даних із SQLite

1. Вкажіть у `settings.py` стару базу (SQLite).
2. Виконайте команду:
    ```
    python manage.py dumpdata --natural-primary --natural-foreign --exclude auth.permission --exclude contenttypes > db.json
    ```

### 3. Переключіть налаштування на PostgreSQL

1. Вкажіть у `settings.py` нову базу (PostgreSQL).
2. Виконайте міграції:
    ```
    python manage.py migrate
    ```

### 4. Завантажте дані у PostgreSQL

```
python manage.py loaddata db.json
```

- Перед імпортом переконайтесь, що структура бази однакова (міграції застосовані).

- Перевірте, чи всі дані коректно перенеслись.
