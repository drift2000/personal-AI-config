# site zhytlokomservis — поточний контекст

## Поточний стан

- Застосунок — Yii 2 Advanced: `frontend`, `backend`, `common` і `console` у `src/`.
- Локальне середовище запускається через `run.sh` і Docker Compose; фактичну конфігурацію визначають `run.sh` та `docker/docker-compose*.yml`.
- Контейнери frontend і backend використовують PHP 7.2 та Apache. Тести запускаються через `run.sh` у контейнері лише після перевірки ізоляції тестових даних.
- Публічним технічним описом структури, запуску й підтримки є кореневий `README.md`; стандартний `src/README.md` описує шаблон Yii, а не локальні операційні домовленості.

## Обмеження та ризики

- `.env`, дані в `data/`, резервні копії, логи й завантаження можуть містити конфіденційні або важливі дані. Не копіювати їх до документації та не виконувати restore, deploy чи зовнішні запити без доручення.
- Дані квитанції отримуються із зовнішнього білінгу. Для діагностики використовувати знеособлені або прикладні дані; реальну відповідь сервісу не вважати перевіреною без окремого дозволу.
- Робоче дерево має незакомічені зміни. Перед змінами зберігати їх і не виконувати commit, reset або push без явного запиту.

## Приватна документація

- Поточний контекст зберігається у цьому файлі; довготривалі рішення — у `decisions/`, тематичні передачі робіт — у `briefs/`, датовані факти — у `history/`.
- Історію, перенесену 2026-10-21, збережено без зміни вмісту. Її резервна копія — в `archive/source-history-backup/`; відновлений фрагмент чату — в `archive/recovered-chat-structure.txt`.
- Проєктні скіли зберігаються приватно в `.agents/skills/` і підключаються у глобальному Codex config через їхні абсолютні шляхи.
- Знеособлена документація зовнішнього білінгу зберігається у
  `docs/billing/`; оригінали матеріалів постачальника локальні та виключені з
  Git через можливу наявність персональних даних.
