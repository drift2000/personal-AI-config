# 0004 — Приватність робочої документації за замовчуванням

Status: accepted
Date: 2026-10-21

## Context

Робочі дослідження, обґрунтування рішень, скіли та історія розробника не повинні автоматично ставати частиною комерційного репозиторію. Водночас репозиторій має лишатися достатнім для підтримки застосунку.

## Decision

Усі нові робочі матеріали спочатку зберігаються в приватному каталозі проєкту. До репозиторію додається лише технічна документація, яку користувач прямо погодив або прямо замовив, і яка потрібна для розробки, тестування, розгортання чи підтримки. Приватні проєктні скіли підключаються за абсолютними шляхами через глобальний Codex config, а не зберігаються у Git.

## Consequences

README та короткі проєктні інструкції можуть бути спільними, але не містять особистої історії, брифів, ADR, приватних шляхів або промптів. Значні майбутні задачі мають приватні brief/ADR лише за умовами глобального скіла.
