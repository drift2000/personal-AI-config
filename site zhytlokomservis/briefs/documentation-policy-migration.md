# Міграція політики приватної та спільної документації

## Goal and scope

Перевести поточний проєкт на принцип «private by default — shared by explicit decision», зберігши самодостатню технічну документацію репозиторію.

## Verified findings

- Кореневий `STRUCTURE.md` був єдиним проєктним описом структури й запуску; його зміст переведено до кореневого README за прямим дорученням.
- Локальні скіли автоматично виявлялися з `.agents/skills/`, але цей шлях знаходиться у робочому дереві.
- Codex підтримує явні користувацькі записи `skills.config` з абсолютним шляхом до папки скіла; це дозволяє лишити скіли поза Git без симлінків.

## Work status / next step

Після перезапуску Codex перевірити, що каталог доступних skills містить обидва шляхи з приватного каталогу. Не створювати нові shared-документи без окремої явної задачі.
